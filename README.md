## 📌 v4.4 版本更新說明 (Release Notes)

### 1. 核心演算法與相容性重構（對齊 `myfate.herokuapp.com` 原站基準）
- **單一資料源架構（Single Source of Truth）**：所有八字核心欄位（四柱、藏干、十神、胎元／命宮／身宮／胎息／空亡／星座、十二長生運星、大運與起運時間、定格局、合化狀態、無敵律數／實律、取用神、李鐵筆日主強弱、四柱神煞、袁天罡秤骨、先天體檢、八宅命卦）統一於 `calculateBazi()` 單次計算完成，UI 渲染層（`renderBaziView`）不再重複推論或改寫結果。
- **干支合化完整支援**：新增完整三支「三合／三合不化」（依 `[長生, 帝旺, 墓庫]` 排序，如 `亥卯未 [(2, 0, 1)]`），修正「半三合／半三合不化」柱位排序與年月拱合判定，並完整支援「五合不化」、「三會／輔助柱三會」、「六合／六合不化」及「相鄰六沖破合」。
- **《無敵律數》實律與取用神校準**：
  - 修正「未月」火、土、水、木係數與天干虛浮無根折減規則。
  - 取用神依全盤最高實律定「病神」，次高實律 $\ge 60$ 時自動切換為「大病神＋小病神＋藥神」雙病神格局。
  - 移除特定西元日期補丁，改以四柱干支結構（`yearGZ_monthGZ_dayGZ_hourGZ`）為唯一基準，確保陽曆、農曆、閏月與不同六十甲子週期計算結果 100% 一致。
- **四柱神煞通用化重構**：移除硬編碼神煞字典，完整實作年支歲前位移神煞（`勾絞 +3`、`五鬼 +4`、`歲破/大耗 +6`、`龍德 +7`、`白虎 +8`、`福德 +9`）、日支查表神煞（`孤辰`、`寡宿`、`驛馬`、`華蓋`、`亡神`）以及 `日貴`、`魁罡`、`鐵掃星` 規則。
- **農曆閏月與小月防呆驗證**：切換農曆時自動依 `leapMonthOfYear(year)` 判斷該年是否真有該閏月（無該閏月時自動停用勾選），並針對農曆小月（29 日）自動收斂日期上限。

### 2. 介面與嵌入模式優化
- **全模式版本標籤（`v4.4`）**：於頂部導覽列、生辰輸入標題旁、經典命盤標題旁與頁尾同步顯示綠底 **`v4.4`** 標籤，即使在 WordPress `<iframe>` 嵌入模式（`?embed=1`）下亦能一眼確認版本已同步。
- **經典直書區塊完整呈現**：於經典區塊完整呈現「袁天罡秤骨法」、「定格局與出生節氣」、「李鐵筆老師日主強度計算（含天干／地支明細與同黨／異黨總分）」、「四柱天合地合／天剋地沖對照表」、「先天體檢（十干統計）」與「八宅命卦」。
